# WCAG помощник

Карманный справочник WCAG 2.2 для QA доступности: пишешь «контраст», получаешь номер критерия, уровень, что проверять и подсказку для Android. Есть проверка контраста двух цветов.

Устанавливается на телефон как приложение (PWA) и работает без интернета.

**Открыть:** https://fakingfanny.github.io/WCAG/

Установка на Android: открыть ссылку в Chrome → ⋮ → «Установить приложение».
